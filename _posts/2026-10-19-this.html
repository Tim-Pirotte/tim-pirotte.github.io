Welcome to the first post on this website. Hopefully one of many. This first article will discuss how and why this site was created.

Why?

Having an online presence is important. That is one of the reasons we have a course on professional networking at school. One of the assignments is to create an e-portfolio showcasing our work and interests, as well as writing about events we attended. A resume often fails to show who you really are, so a website can be really helpful for a recruiter to get to know you.

What?

Creating a site that is visually distinct and has an identity, instead of just using a template and calling it a day, was important for me. The latter feels lazy to me. The chosen theme is a less busy version of a 90s website. Accessibility is important so stuffing the site with a bunch of attention-grabbing GIFs was not an option. Instead images from bettysgraphics.neocities.org were used to still give an older look. Since there is still a lot of color, which may cause contrast issues, a button was added to switch to a simpler theme that is easier on the eyes. At the time of writing this post, the CSS for it has not been finished, but I hope to get that done as soon as possible.

Currently, the only finished page is "posts". Every page should have a creative element to make it more engaging. For the "posts" page, I recreated the old user interface of Google search. Some dynamic elements were added, such as a post counter and a randomized search time. I am still thinking about what to do for the other pages.

Lastly, since bettysgraphics.neocities.org offers so many interesting backgrounds, every post will feature a different one.

How?

GitHub offers free static site hosting with Jekyll. A repository was going to be created anyway to back up any changes, so I put the site on GitHub Pages for the moment. So far it seems to work great. There are some limits, but most people won't exceed them. Call me old-school, but I like writing code by hand. And yes, that includes CSS (although I wouldn't consider that a programming language). There might be a post about AI later, but it wasn't used for this site apart from as a search engine. Everything is just plain old HTML, CSS and JavaScript. A local instance of Jekyll is used to test changes before pushing.

And that is basically it. I tried to keep things simple so I wouldn't spend tens of hours on this. I am not really a designer (or a writer), so if you have some tips for me on how to improve this site, please reach out.
That is all for now. Thank you for taking the time to read this.
